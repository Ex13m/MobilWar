# MobilWar — техническое задание на полноценный AR-бой

Версия 1.0 · 13.09.2026 · Документ для стороннего эксперта (продюсер / ведущий инженер), который не погружён в проект.

---

## 0. Что это за продукт в одном абзаце

MobilWar — многопользовательский AR-шутер на реальной местности. Игроки (4–16 человек, в первую очередь школьники 10–16 лет под присмотром взрослого-судьи) выходят на двор или в парк, открывают веб-приложение на обычном смартфоне (без установки из магазинов) и видят друг друга как 3D-аватаров, стоящих там, где стоит живой человек. Телефон — оружие: куда направлен телефон, туда летит заряд. Позиция берётся с GPS, направление — с компаса и гироскопа. Можно ставить на землю AR-объекты (турели, укрытия, дроны), подбирать бонусы, вызывать артиллерию. Есть режим без экрана: телефон в руке, всё через звук и вибрацию. Игра одна на весь мир (единая сеть зон), бой всегда локальный (одна площадка ~100–300 м).

Текущее состояние: работающий MVP-1 (см. §9) — сервер, AR-клиент, режим без экрана, страница судьи, деплой. Это ТЗ описывает следующий уровень — «полноценный AR-бой» с ростером оружия, отдачей, поддержкой с воздуха, ящиками снабжения и AAA-подачей.

## 1. Ключевое физическое ограничение, от которого пляшет весь дизайн

Смартфон даёт: **GPS ±3–8 м** на открытом месте (±15–30 м у зданий), **компас ±3–10°** (хуже после магнитных помех), обновление позиции 1 раз в секунду. Это значит:

- на дистанции 20 м ошибка позиции цели ±5 м ≈ ±14° угла. Точнее компаса нет смысла требовать;
- «попал / не попал» нельзя считать как в обычном шутере (луч в хитбокс). Считаем **конус попадания**, ширина которого = максимум из (точность оружия, угловой размер GPS-ошибки цели);
- реальные различия оружия по точности видны только на **ближних дистанциях (до 10–15 м)** и в **скорости/урону/дальности/особенностях**. Так и проектируем: пистолет «точный до 10 м» — это честная формулировка;
- сервер — единственный источник истины по попаданиям, урону, очкам; клиент только рисует и предсказывает.

Формула конуса (уже реализована): `halfAngle = max(weaponCone, atan((3 м + ½·(accStrelka + accCeli)) / dist))`, где acc — точность GPS каждого телефона в метрах.

### 2.2 Модель точности (единая для всех)

```
cone(t) = clamp(base + bloom(t) − aimBonus, min, max)
bloom(t): винтовка +0.8°/выстрел, распад 10°/с; вулкан −3°/с при огне; снайперка 0
aimBonus: снайперка в прицеле −9°; «задержка дыхания» −2°
итоговый конус = max(cone, gpsCone(dist, acc))
попадание: угол между курсом телефона и пеленгом на цель ≤ итоговый конус
при нескольких целях в конусе — ближайшая к центру, затем ближняя
```

Дистанционный спад урона: 100 % до 60 % дальности, далее линейно до 40 % на максимуме (у снайперки без спада).

### 2.3 Модель отдачи («эффект отдачи»)

Реальную камеру телефона сдвинуть нельзя, поэтому отдача — это три слоя, которые вместе дают физическое ощущение:

1. **Визуальный кик камеры**: виртуальная камера получает импульс по тангажу вверх и случайно по рысканью, мир на экране «подпрыгивает» и за 120–250 мс возвращается пружиной (критическое демпфирование). Пистолет 0.6°, винтовка 0.4°/выстрел (накапливается до 3°), вулкан 0.25° но постоянная тряска, снайперка 2.5° + затемнение прицела 150 мс, ракетомёт 3° + сдвиг назад.
2. **Отдача 3D-модели оружия** (viewmodel): откат назад по оси ствола 3–8 см, подъём затыльника, вспышка на дульном срезе (спрайт + точечный свет 1 кадр), гильза/энергоячейка для винтовки. Возврат пружиной с небольшим перелётом.
3. **Тактильный + звуковой слой**: вибрация 10–20 мс на выстрел (Android; на iPhone Vibration API нет — компенсируем звуком), низкочастотный «тук» в звуке выстрела, стерео-хвост эха на улице.

Функциональная отдача = рост конуса (bloom) из §2.2. Игрок это чувствует как «очередь расползается».

### 2.4 Перезарядка и смена оружия

- Перезарядка запускается кнопкой или автоматически при пустом магазине; во время неё стрелять нельзя, смена оружия прерывает.
- Каждая перезарядка — 3-фазная анимация модели + 3 звука (извлечение, установка, досыл). Быстрая перезарядка винтовки (тактическая) — 2 фазы.
- Смена оружия — свайп по панели или кнопка; пистолет достаётся за 0.25 с, тяжёлое за 0.8 с.
- В режиме без экрана: перезарядка — встряхнуть телефон вниз; смена — двойной тап.

## 3. Классы и экипировка

Класс выбирается в лобби и при каждом возрождении. Меняет стартовый набор и один пассивный бонус, не меняет HP (100 у всех) — баланс за счёт ролей, не статов.

| Класс | Основное | Снаряжение | Пассив | Для кого |
|---|---|---|---|---|
| Штурмовик | Гроза | плазма ×2 | +1 очко снабжения | база, для новичков |
| Разведчик | Искра + Гроза (укороченный магазин 20) | ЭМИ ×1 | возрождение на 3 с быстрее, видит бонусы на радаре за 40 м | быстрые дети |
| Снайпер | Горизонт | плазма ×1 | «задержка дыхания» 5 с вместо 3 | терпеливые |
| Тяжёлый | Вулкан | — | стартовый щит 25, укрытия за 0 очков (1 шт.) | держать точку |
| Медик | Гроза | — | аура лечения 2 HP/с союзникам в 3 м, оживляет «раненых» касанием (см. §5.3) | командные |
| Инженер | Искра | ЭМИ ×1 | турели и дроны на 1 очко дешевле, чинит объекты (стоять 3 с рядом) | строители |

У всех всегда есть пистолет «Искра» как запасное. Тяжёлое (ракетомёт) — только из ящика или бонуса.

### 3.1 Броня

Броня = очки щита, тратятся раньше HP, не восстанавливаются сами.
- Лёгкая (бонус «щит»): 50.
- Тяжёлая (из ящика снабжения): 100, но носящий стреляет из Вулкана/Молота без штрафа за движение — компенсация.
- ЭМИ снимает щит полностью.

## 4. Бонусы, ящики, поддержка с воздуха

### 4.1 Наземные бонусы (уже реализовано, расширяем)

Сервер спавнит в случайных точках зоны (равномерно по площади, не ближе 15 м к базам): первый через 6 с, далее каждые 20 с, до 4 одновременно, живут 90 с. Подбор — подойти на 3 м. Виды: аптечка +50, боезапас (+2 ракеты / +1 магазин всем), щит 50, overcharge ×2 урона 20 с, снабжение +2 очка, **гранаты ×2**.

В AR: парящая светящаяся иконка с лучом света вверх (виден с 50 м) и вращением; в режиме без экрана голос называет ближайший бонус и направление.

### 4.2 АР-ящики снабжения («воздушные сбросы»)

Каждые 2 мин (настраивается судьёй) в случайную точку зоны сбрасывается капсула:
1. За 10 с до посадки — всем звук самолёта/дрона и голосовое «Сброс на 2 часа, 60 метров»; в AR виден спускающийся контейнер на парашюте, на карте судьи — точка.
2. После посадки — столб цветного дыма высотой 15 м (3D-эффект, виден из любой точки зоны) 60 с.
3. **Вскрытие**: стоять в 2 м от ящика 3 с, не стреляя (шкала на экране). Если рядом противник — таймер сбрасывается: ящик «оспаривается».
4. Содержимое (случайно, с весами): тяжёлая броня 30 %, ракетомёт с 2 ракетами 25 %, снайперка с 10 патронами 15 %, набор гранат 20 %, «маяк артиллерии» (одноразовый вызов артудара) 10 %.

### 4.3 Поддержка с воздуха и артиллерия (килстрики + бонусы)

Награды за серию убийств без смерти (счётчик виден в HUD), либо из ящика. Вызов — кнопка поддержки → выбор точки: направление = куда смотрит телефон, дистанция = ползунок 10–80 м (или тап по мини-карте). Все получают предупреждение, у судьи есть глобальный выключатель.

| Серия | Поддержка | Что происходит | Урон | Контрмера |
|---|---|---|---|---|
| 3 | **Разведдрон** | все противники на радаре 15 с, их аватары подсвечены сквозь укрытия | — | ЭМИ сбивает |
| 5 | **Артудар** | 5 с сирены + красный круг r=8 м в AR и на карте, затем 3 снаряда с интервалом 1 с; каждый — взрыв сплэш 8 м, 60 → 20 урона | до 180 | выйти из круга (8 м за 5 с — реально) |
| 7 | **Авиаудар** | полоса 40 × 6 м вдоль курса, через 2 с пролёт штурмовика, 20 зарядов 15 урона по полосе | до 90 при попадании под все | лечь в укрытие (укрытие блокирует) |
| 10 | **Орбитальный луч** | круг 12 м, 3 с заряд (звук нарастает), 100 урона, сжигает объекты | 100 | ЭМИ отменяет за 1 с до удара |

Не более одного вызова в 45 с на команду, чтобы игра не превратилась в ожидание.

## 5. Бой: HP, смерть, возрождение, отклик попаданий

### 5.1 Шкала жизней и щита
Крупная шкала внизу экрана: 100 HP по сегментам 10 (каждое попадание бластера — один сегмент), поверх — голубая полоса щита. Число HP крупно. Ниже 25 HP: сердцебиение в звуке, красная пульсирующая рамка, лёгкое обесцвечивание картинки.

### 5.2 Отклик попаданий
- **Стрелок**: белый «хит-маркер» на прицеле, всплывающая цифра урона у цели (белая; жёлтая при щите; красная при добивании), короткий звук подтверждения, вибрация 15 мс; убийство — «К.О.» баннер, звуковой аккорд, вибрация 3×30 мс, +к серии.
- **Жертва**: направленный индикатор урона (дуга на краю экрана со стороны стрелка), красная вспышка с силой ∝ урону, тряска камеры, вибрация 60–300 мс, аватар мигает белым для всех остальных. Щит принял урон — голубая рябь по пузырю.
- **Смерть**: замедление и обесцвечивание 1 с, экран «Ты выбыл», кто и чем убил, таймер 8 с.

### 5.3 Выход из мертвяка (реализовано, расширяем)
1. 8 с обязательного ожидания. Экран серый, стрелка и дистанция до своей базы (север/юг зоны на 55 % радиуса).
2. Дойти до базы (8 м) → возрождение с полным HP, стартовым набором класса и 3 с неуязвимости (пузырь).
3. Не дошёл за 22 с → авто-возрождение на месте (младшие/усталые не выпадают).
4. Расширение «раненый»: первые 8 с игрок не мёртв, а «ранен» — Медик может оживить касанием (стоять рядом 3 с) без похода на базу.

### 5.4 Укрытия и препятствия
Укрытие — дуга 2 м; блокирует любой выстрел, линия которого проходит ближе 1.6 м от центра; ракета взрывается о него; артиллерия и орбитальный луч пробивают; авиаудар — нет. Реальные препятствия (деревья, стены) не учитываются — GPS не знает о них; это компенсируется тем, что игроки сами используют реальные укрытия, чтобы их **не видел** противник (не видишь — не наведёшься).

## 7. Технические требования

### 7.1 Стек (текущий, менять не нужно)
- Монорепо pnpm, TypeScript. `packages/shared` — гео-математика, протокол, боевые формулы. `apps/server` — Node 22 + ws, симуляция 10 Гц, SQLite. `apps/client` — Vite + three.js r186, PWA. Cloudflare-адаптер (`deploy/higgsfield`) — Durable Objects.
- Клиентские библиотеки для качества: `postprocessing` (bloom для зарядов и взрывов), собственная система частиц (уже написана: `apps/client/src/fx`), Web Audio с HRTF и свёрточной реверберацией, GLTFLoader + Draco/Meshopt для моделей.

### 7.2 Сервер (доработки к реализованному)
- Оружие как данные: таблица параметров в `constants.ts`, состояние на игрока: `weapon, mag, reserve, reloadUntil, bloom, spinUp, heat, chargeStart, zoom`.
- Проверки на сервере: темп стрельбы, магазин, перегрев, скорость для Вулкана, заряд снайперки (сервер считает по времени между `charge_start` и `shoot`).
- Гранаты и артиллерия — серверные снаряды/таймеры (как ракета), события всем клиентам с координатами для отрисовки.
- Ящики: серверный объект с фазами `dropping → landed → opening(by, progress) → opened`.
- Килстрики: счётчик на игроке, обнуляется смертью.
- Протокол: `shoot{weapon, heading, pitch, charged}`, `reload`, `weapon`, `grenade{kind, heading, pitch}`, `support{kind, heading, distM}`, `crate_open`; события `explosion`, `strike_warning`, `crate`, `streak`.
- Античит: всё выше — серверные таймеры; клиентские значения только как заявка.

### 7.3 Клиент
- **Viewmodel**: 3D-модель оружия в нижнем правом углу камеры, с анимациями: idle-покачивание (дыхание), ходьба (по скорости GPS), выстрел (кик), перезарядка (3 фазы), смена (уход/приход), прицел снайперки (модель уезжает, появляется рамка прицела).
- **Снаряды**: бластерные заряды — светящиеся капсулы с трейлом и точечным светом (лимит 4 света), 70 м/с; ракеты — модель с факелом и дымом; гранаты — дуга; артиллерия — падающие трассеры сверху.
- **Взрывы**: огненный шар + ударное кольцо + 200 частиц + свет + тряска камеры по дистанции.
- **HUD**: шкала HP/щита, магазин/запас, панель оружия, кнопка гранаты, кнопка поддержки с серией, хит-маркер, направленный урон, мини-радар, компас, стрелка на базу в мертвяке, лента событий, баннеры.
- **Снайперский зум**: FOV 22°, видеоподложка масштабируется тем же коэффициентом, качание прицела = сырые данные гироскопа ×0.5, кнопка «дыхание».
- **Производительность**: 60 fps на телефонах 2021+, 30 fps на бюджетных; бюджет 3 МБ загрузки, ≤ 80k треугольников в кадре, ≤ 4 динамических света.
- **Ассеты**: модели GLB ≤ 150 КБ каждая (Draco), текстуры ≤ 1024², звуки OGG. Источники: CC0 (Kenney Blaster Kit, Quaternius), генерация Meshy/Higgsfield с ретопологией, либо собственный моделлер (см. §8, роль 3D-художника).

### 7.4 Список ассетов к производству
Модели (GLB): Искра, Гроза, Горизонт, Вулкан, Молот, плазма-граната, ЭМИ-граната, ракета, ящик снабжения + парашют, турель, укрытие, дрон, 5 иконок бонусов, 6 аватаров (по классам) с 3 анимациями (idle, попадание, смерть), база-маяк.
Звуки (OGG): 7 оружий × (выстрел, хвост, перезарядка 2–3 фазы, пусто) ≈ 40; взрывы 3 вида; попадания 3; подбор 5; HUD 6; поддержка с воздуха 4 (сирена, самолёт, дрон, луч); голос диктора (TTS ru, 20 фраз).
Текстуры/спрайты: вспышка, дым, искра, кольцо удара, дульный свет.

## 8. Систематизация разработки

### 8.1 Роли
| Роль | Зона | Загрузка |
|---|---|---|
| Продюсер / гейм-дизайнер | баланс, полевые тесты, приоритеты | 0.5 |
| Инженер геймплея (TS/three.js) | клиент: оружие, эффекты, HUD | 1.0 |
| Бэкенд-инженер (TS/Node/Cloudflare) | сервер, протокол, античит, деплой | 0.5 |
| 3D/VFX-художник | модели, анимации, частицы, стиль | 0.5–1.0 |
| Звуковой дизайнер | §2.5, §7.4 | 0.3 |
| Полевой тестировщик (учитель/вожатый) | тесты с группой 6–12 детей | по событиям |

### 8.2 Этапы и критерии приёмки

**Этап A — «Оружие и отдача» (2–3 недели)**
- A1 Серверные параметры 7 видов оружия, магазины, перезарядка, перегрев, заряд, зум. Тесты на каждое правило. Приёмка: e2e-тест «винтовка расползается после 10 выстрелов, восстанавливается за 1 с»; «Вулкан не стреляет при 2 м/с».
- A2 Viewmodel с анимациями, отдача камеры, дульная вспышка, заряды-снаряды, взрывы. Приёмка: видео с телефона 60 fps, субъективная оценка 5 тестеров ≥ 4/5 по «ощущается выстрел».
- A3 Звук: 40 файлов, спатиализация, реверберация. Приёмка: с закрытыми глазами тестер указывает направление выстрела в 70 % случаев.
- A4 HUD: шкала, магазины, панель оружия, хит-маркер, направленный урон. Приёмка: новичок без объяснений понимает, что его ранили и откуда, за 1 бой.

**Этап B — «Снабжение и поддержка» (2 недели)**
- B1 Гранаты с броском по наклону. B2 Ящики с оспариванием и дымом. B3 Килстрики: разведка, артудар, авиаудар, луч. B4 Классы и броня. Приёмка: полевой тест 8 игроков × 3 раунда, каждый вид поддержки сработал хотя бы раз, средняя оценка веселья ≥ 4/5, ни одной травмы/выхода на дорогу.

**Этап C — «AAA-подача» (2 недели)**
- C1 Финальные модели и аватары, bloom, погодные частицы (пыль/искры в воздухе). C2 Диктор и музыкальные стинги. C3 Онбординг с тиром (первый выстрел за 30 с). C4 Полировка режима без экрана под новый арсенал. Приёмка: удержание «второй раунд» ≥ 80 %.

**Этап D — «Масштаб» (по мере роста)**
- Postgres + Redis, процесс на зону, XP и косметика, турниры между школами, нативная обёртка для ARKit/ARCore Geospatial (см. ROADMAP).

### 8.3 Процесс
- Ветка на фичу → CI (typecheck, тесты, сборка) → предпросмотр → полевой тест по чек-листу → merge.
- Каждое число баланса — только в `constants.ts`; изменение баланса = PR с обоснованием из логов боёв (сервер пишет: попадания, промахи, TTK, дистанции).
- Определение готовности: тесты зелёные, работает на iPhone (Safari) и Android (Chrome), в AR и без экрана, судья видит, документ обновлён.
- Метрики боя: точность (попадания/выстрелы) по оружию 25–45 %, TTK 1–3 с, средняя дистанция боя 10–30 м, доля времени в мертвяке < 20 %, смерти от артиллерии < 15 % всех.

### 8.4 Риски и как снимаем
| Риск | Снятие |
|---|---|
| GPS «плывёт», попадания кажутся случайными | конус по точности, хит-маркеры и цифры урона объясняют; судья видит точность каждого; предупреждение «плохой GPS» |
| Компас врёт после калибровки | подсказка «восьмёрка», индикатор качества, в бою — ориентир по аватарам (если аватар стоит не там, где человек, крутить телефон до совпадения — ручная калибровка) |
| iOS: нет вибрации, нет WebXR | звук вместо вибрации; AR-lite (видео + гироскоп) — уже работает |
| Дети бегут через дорогу | геозона, судья, «стоп» на весь бой одной кнопкой, правила при входе |
| Слабые телефоны | уровни качества: частицы ×0.3, без bloom, 30 fps |
| Ассеты дорогие | CC0-библиотеки + генерация; список в §7.4 приоритизирован: сначала 3 оружия и взрыв |
