# Дорожная карта

## MVP-1 (этот репозиторий) — «двор, 2–8 игроков»
- [x] Монорепо, shared-ядро (гео, конус попадания, античит), тесты
- [x] Авторитарный сервер: комнаты-зоны, TDM/CTF/KOTH/Заражение/Оборона турелей, турели, аптечки, укрытия, геозона, судья, SQLite
- [x] Клиент: лобби, AR-lite (iOS/Android), WebXR (Android Chrome), режим без экрана с аудио-радаром и TTS, HUD, мини-радар
- [x] Страница судьи: карта, старт/стоп/сброс, смена режима, зона, кик
- [x] CI, Docker, render.yaml
- [ ] Полевой тест с 4–8 телефонами: калибровка `CONE_HALF_ANGLE_DEG`, `HIT_RADIUS_BASE_M`, `MAX_ACCURACY_M`
- [ ] Иконки PNG 192/512 для PWA (сейчас SVG)

## MVP-2 — «школа»
- Полигональная геозона в UI судьи (рисование на карте) + проверка близости дорог (OSM Overpass)
- XP/уровни/косметика (только внешность), таблица лидеров зоны
- Мины, радарный маяк, снайперка/дробовик (баланс по GDD)
- Персональные комнаты по QR-коду, приглашения
- Постоянный «мир»: карта всех зон, история матчей
- Postgres + Redis pub/sub, процесс на зону, health-метрики
- Playwright e2e в CI (лобби → игра → судья)

## v1 — «город»
- Нативная обёртка (Capacitor) для iOS: ARKit/ARCore Geospatial API — сантиметровая привязка турелей к местности
- VPS-привязка (Niantic Spatial / ARCore Geospatial) там, где есть покрытие
- Голосовой чат команды (WebRTC), реплеи матчей
- Турниры между школами, режим редактора карт
- Родительский портал, возрастная верификация, монетизация только косметикой
