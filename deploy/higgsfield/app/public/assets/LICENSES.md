# Сторонние ассеты

- `models/*.glb`, `models/Textures/colormap.png`, `sprites/*.png`, `sfx/*.ogg` — Kenney (kenney.nl), лицензия CC0 1.0. Наборы: Blaster Kit, Weapon Pack, Space Kit, Particle Pack, Digital Audio, Impact Sounds, Interface Sounds. Скачаны с GitHub-зеркал (shorepine/kenney, ETdoFresh/kenney.nl).
- `models/fps/*` и `sfx/blaster.ogg`, `sfx/enemy_destroy.ogg`, `sfx/weapon_change.ogg` — Kenney Starter Kit FPS (github.com/KenneyNL/Starter-Kit-FPS), ассеты CC0, код MIT.
- `sfx/gen/*.ogg` — кинематографические sci-fi звуки оружия/попаданий/интерфейса, сгенерированы для проекта через Higgsfield (модель Mirelo text-to-audio), обработаны ffmpeg (loudnorm −16 LUFS, Vorbis q2, моно 44.1 кГц). Права на результат — у проекта; без сторонних лицензий.
- `art/*.webp` — аниме-sci-fi заставки (лобби, старт раунда, победа, выбывание), сгенерированы для проекта через Higgsfield (Recraft V4.1) по палитре `docs/DESIGN.md`, сжаты в WebP 720 px. Права на результат — у проекта; без сторонних лицензий.
